# H743II 示波器与信号发生器 (H743II_OSC_GEN_v1.4)

## 项目概述
基于STM32H743II微控制器的**多功能示波器与信号发生器**设备。集成触摸屏交互界面、高精度信号采集与生成功能。

## 核心功能

### 1. 示波器模块 (`proj_page/osc_logic.c`)
- **信号采集**：双通道ADC采集，采样频率可达3.6MHz
- **波形分析**：1024点FFT快速傅里叶变换
- **波形分类**：支持波形特征提取与自动分类
- **实时显示**：触摸屏显示采集波形与频谱

### 2. 信号发生器模块 (`proj_page/gen_logic.c`)
- **时钟生成**：通过SI5351芯片生成可配置频率的时钟信号
- **DAC输出**：数模转换输出信号
- **多频率支持**：灵活的频率设置范围

### 3. 显示与交互 (`proj_lcd_main/`)
- **LCD驱动**：LTDC LCD控制器驱动
- **触摸输入**：电容触摸屏交互
- **页面管理**：多页面（示波器/发生器/设计）UI管理

## 项目结构

| 目录 | 说明 |
|------|------|
| `Core/` | STM32 HAL库核心驱动（GPIO、UART、DMA、定时器等） |
| `Drivers/` | CMSIS标准库与HAL驱动 |
| `proj_bsp/` | 板级支持包（DWT、SDRAM、LCD、SI5351、触摸屏） |
| `proj_level1/` | 底层控制模块（ADC、DAC、定时器控制） |
| `proj_lcd_main/` | LCD UI层（内存管理、触摸逻辑、类型定义） |
| `proj_page/` | 业务逻辑层（示波器/发生器/显示逻辑） |
| `proj_mcore/` | 算法核心（波形分类、特征提取） |
| `proj_value/` | 辅助功能（字体、窗口值管理） |
| `proj_test/` | 测试模块 |

## 关键特性

- ✅ **双通道ADC**：支持同步采集两路信号
- ✅ **FFT分析**：1024点频域分析，误差控制 < 5%
- ✅ **智能采样**：支持等时分割(ETS)与过采样
- ✅ **3.6MHz采样率**：高精度信号还原
- ✅ **触摸UI**：完整的用户交互界面
- ✅ **SDRAM支持**：大容量数据缓存
- ✅ **波形分类**：自动识别与分类输入信号

## 硬件依赖

- **MCU**：STM32H743IITx
- **外设集成**：DMA、DMA2D、FMC、I2C、LTDC、USART
- **外部芯片**：SI5351（时钟生成器）
- **存储**：SDRAM、内部Flash
- **交互**：电容触摸屏、LCD显示

## 编译与构建

项目使用CMake构建系统，生成文件在 `build/` 目录：
```bash
cd build
cmake ..
cmake --build .
```
